What Yoast says about its sitemap

The sitemap index and individual sitemaps in Yoast SEO are updated automatically as you add or remove content. Post types marked as noindex will not appear in the sitemap.

Yoast removed the priority variables from its XML sitemaps in version 3.5, as Google has said publicly that it does not use them on most sites. XML sitemap responses carry an x-robots-tag header with the value noindex, follow.
